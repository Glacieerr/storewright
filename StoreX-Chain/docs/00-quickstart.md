# 5 分钟上手

[English](00-quickstart.en.md)

StoreX 全链路是一家综合店整条供应链的区域数字孪生：远洋班轮、货机、洲际班列和长途货车，经过港口、机场货站、物流园和配送中心，一直到门店的货架。仿真、三维、调度台和值班助手都在浏览器里运行。这是个人作品集 / 开源项目，**本项目与任何零售商、企业无隶属关系**，区域、门店、商品和所有数字都是合成的。

功能很多，第一次不用全看。按下面三步走，5 分钟就能知道它是什么、能做什么、接下来该看哪里。

## 一、打开它（二选一）

- **在线演示**（不用安装）：<https://glacieerr.github.io/storewright/storex-chain/>（首次推送、部署以后可用）。在线版是静态网页，没有本机的孪生服务，其余功能都一样。
- **在本机运行**（需要 [Node.js 22](https://nodejs.org/)）：

  ```bash
  git clone https://github.com/Glacieerr/storewright.git
  cd storewright && npm ci
  npm run dev -w storex-chain
  ```

  然后打开 <http://localhost:5182>。第一次打开要生成区域、仿真 18 周，大约等 5–10 秒。

第一次打开时，三维画面上会出现欢迎卡，给你三条路：看集装箱导览、做一道练习、自己看看（选「自己看看」会有 30 秒的界面导览，顶栏的「?」随时再看）。

## 二、先试这 5 件事

| 试什么 | 怎么做 | 你会看到 |
|---|---|---|
| 1. 一个集装箱从船到货架 | 欢迎卡的第一个按钮，或者打开 `?tour=container` | 一分钟的自动导览：镜头跟着一个集装箱，从班轮靠泊、卸船、堆场、拖车、配送中心，一直到门店货架；每一段都有从仿真里算出来的数字 |
| 2. 场景库 | 顶栏「场景库」，点一张卡片 | 10 个精选场景：港口拥堵演练、机场关闭、高峰负荷、极端负荷的夜里、门店早上收货高峰、冷链门减半、随机区域、自定义区域…… 点一下就切过去 |
| 3. 分享链接 | 顶栏「分享」→「复制链接」 | 链接里有区域、方案、日子、负荷、演练、设施改动、时刻和镜头，别人打开看到的和你一样；也可以导出 / 导入场景文件（格式见 [场景文件和分享链接](07-scenarios.md)） |
| 4. 演练 | 「演练」选「港口拥堵」，点「运行」 | 港口、闸口怎么排队，调度台上哪些作业受影响，分层看板的告警怎么往上报 |
| 5. 值班助手 | 在页面下方的值班助手里问「现在哪些车晚了」「港口那边怎么样」「要是高速封两个钟头会怎样」 | 回答分「结论 / 依据 / 把握 / 下一步」，数字都能在数据里找到出处；要改计划的建议只提交给你确认，不会自己执行 |

## 界面速览

| 区域 | 用途 |
|---|---|
| 顶部的控件 | 方案（上一代 / StoreX / 全链路）、区域（默认 / 随机 / 自定义）、负荷、演练、日子，改完点「运行」 |
| 三维画面 | 拖动旋转、滚轮缩放、点车看路线；下面一排是镜头预设和图层（地名、规划图、车辆标签、监控画面、对比回放、天气、画质） |
| 时间轴 | 播放、暂停、拖到任一时刻；整个页面都跟着这个时钟 |
| 值班助手、分层看板、闭环孪生、调度台 | 页面往下滚：问问题和审批；四层指标和告警；现场 → 感知 → 孪生 → 建议 → 指令；当天的全部作业 |
| 顶栏 | 「分享」「场景库」「练习」「?」、页签（对比与报告、网络规划、说明）、中文 / English |

## 常见问题

- **打开有点慢？** 第一次打开要在浏览器里生成区域、仿真 18 周、排好港口和物流园一天的作业，一般 5–10 秒。网速慢时，主程序以外的部分（报告、网络规划、说明、管理台、值班助手的语言模型）都是用到时才下载。
- **数据是真的吗？** 不是。区域、门店、商品、船期和所有数字都是合成的；设备和运价取公开资料里的常见区间。只用于演示、教学和研究，不用于真实的生产决策。
- **能换成英文吗？** 顶栏右边的「EN」，或者在网址后面加 `?lang=en`。内置的值班助手用中文回答（可选的大模型模式可以用英文）。
- **欢迎卡不想再看？** 勾选「不再显示」；或者在网址后面加 `?onboard=0`。
- **想用自己的数据或设施？** 先在管理台里改设施、在场景文件里写设置（[场景文件和分享链接](07-scenarios.md)）；要接自己的系统见 [扩展指南](05-extending.md)。
