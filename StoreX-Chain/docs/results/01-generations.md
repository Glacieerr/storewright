# 结果 1：三代全链路对比

> 数字来自 `npm run reports` 的全链路仿真（合成数据，每次 18 周，前 10 周预热、后 8 周计入）。「±」后面是 95% 置信区间的半宽；三代用同一组种子（同样的需求、促销和船期），配对差值的置信区间不含 0 才判为「改善 / 变差」。

每一代 20 个种子。上一代 = Storewright 的门店 + 传统供应链；StoreX = 门店升级成 StoreX，上游不变；StoreX 全链路 = 门店 + 上游一起由全链路数字孪生协同。区域里只有一家综合店（综合店，规模约为 StoreX 门店的 2.5 倍），每天约 7.3 千箱。海运、铁路班列和空运的货先进配送中心，再用卡车送店；长途公路（国内、跨境）的整车由货流规划决定直送门店还是进配送中心，全链路里 65% 的长途整车直送门店（见[结果 6](06-flows.md)）。
