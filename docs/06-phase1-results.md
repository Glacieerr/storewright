## 2. 校准：基线是否像真实门店

| 指标 | 仿真基线 | 公开参照 |
|---|---|---|
| 拣货效率 | 74 件 / 拣货工时 | 门店人工拣货 60–70 件/小时（McKinsey）；实地报道约 70 件/小时 |
| 平均到店等待 | 6.3 分钟 | 2019 年路边取货调查平均 5 分 21 秒，各零售商 3–7 分钟 |
| 货架缺货（找不到）比例 | 约 4% 的订单行 | 行业平均缺货率约 8%，其中约 25% 是「店里有货但不在货架上」 |

**基线刻意设得偏强**：基线已经在顾客点击「我在路上」时开始准备（行业常见做法），而不是到店后才开始。宁可低估本系统的改进。

## 3. 主要结果（中型店，30 次重复）

### 3.1 两个配置档位对比基线

| 指标 | 基线 | 默认档位（服务与安全优先） | 效率优先档位 |
|---|---|---|---|
| 超重框 / 压坏风险框 / 化学品混装框 | 11.4% / 19.4% / 11.1% | **0 / 0 / 0** | **0 / 0 / 0** |
| 订单满足率（含替代） | 97.94% | **98.95%**（+1.0 个百分点） | **98.95%** |
| 缺货行销售额 / 天 | $818 | **$392**（−52%） | **$391** |
| 平均到店等待 | 6.28 min | **5.34 min（−15%）** | 6.24 min（无显著差异） |
| 等待 ≥ 8 分钟的比例 | 15.2% | **10.9%（−29%）** | 15.0% |
| 未按时就绪订单 | 5.3% | **3.2%（−39%）** | 8.6%（变差） |
| 已取出订单门口停留（冷链风险） | 10.7 min | **2.1 min（−81%）** | **2.3 min** |
| 每件行走距离 | 6.63 m | 7.15 m（+8%） | **5.48 m（−17%）** |
| 作业总工时 / 天 | 129.4 h | 135.7 h（+4.9%） | 129.9 h（+0.4%） |
| 净额 / 年（人工成本 vs 挽回毛利，只计这两项） | — | −$11,454 | **+$34,314** |

### 3.2 怎么读这张表

1. **安全与质量的改进是确定的**：超重、压坏风险、化学品混装三项在两个档位下都降到 0；挽回约一半的缺货行；门口停留缩短约 80%。
2. **默认档位用约 5% 的工时换来更好的服务**：同一订单同温区的框放在同一辆车上，订单就绪更早、等待更短；代价是推车装得不够满、行走更多。
3. **效率优先档位工时持平、财务为正**，但更多订单不能按时就绪。
4. **没有一个档位在所有指标上都赢**——这正是「定制化」的意义：门店按自己的优先级选择档位，并在上线前先在仿真中看到取舍。

## 4. 每项优化的贡献（消融实验）

在基线上每次只打开一项优化：

| 单项 | 主要作用 | 代价 |
|---|---|---|
| 体积 + 重量 + 压放 + 化学品分装 | 安全与质量问题降到 0 | 每单多 0.6 个框，作业工时 +7.4 h/天（最大的成本项） |
| 按通道重叠度分批 | 拣货工时 −1.6 h，每件行走 −9% | 订单被拆到多辆车时，等待 +1.0 min |
| 旅行商路线 | 拣货工时 −1.5 h，每件行走 −8% | 无 |
| 冷链时限约束 | 在本场景下几乎不触发（冷链批次本来就短） | 无，作为安全保障 |
| 扫描记录暂存格位 | 交付工时 −6.8 h，等待 −1.0 min | 暂存每框多几秒 |
| 位置估算触发准备（固定 5 分钟阈值） | 门口停留 −9.4 min | 单独打开时等待 +2.3 min（取框太慢时来不及），与格位记录组合后抵消 |
| 一个行程一次核验 | 交付工时 −0.2 h | 无 |
| 后仓补取 | 满足率 +1.0 个百分点 | 工时 +5.6 h/天 |

## 5. 结论对假设有多敏感

[敏感性分析](results/medium-sensitivity.md) 逐个把 8 个假设参数调到低值和高值：

- **等待改善、满足率提升、门口停留缩短在所有设置下都成立**；
- **工时增加在所有设置下都成立**（+4.0 到 +10.3 h/天），对**框装填系数**最敏感（0.6 → +10.3 h；0.8 → +4.0 h），其次是暂存扫描时间和不记录格位时的寻找时间；
- 因此「默认档位工时略增」是稳健的结论，不是某个参数凑出来的。

## 6. 规模伸缩

| 模板 | 日均订单 | 默认档位：等待 | 默认档位：工时 | 效率档位：净额 / 年 |
|---|---|---|---|---|
| 小型（单层） | 69 | −11% | +5.1% | +$6,168 |
| 中型（单层） | 260 | −15% | +4.9% | +$34,314 |
| 大型（两层） | 654 | −11% | +4.3% | +$114,502 |

三个模板使用同一套 schema 和代码，结论方向一致。

## 7. 局限（必须如实说明）

- 全部为合成数据；作业时间参数是假设，已在报告中列出并做敏感性分析；
- 排班是固定的（每小时人数），还没有 AI 人员调配（Phase 5），也没有按产能限流；
- 没有模拟拣货员之间的拥堵、顾客对通道的占用；
- 后仓补取带来的**货架补货收益**（让到店顾客也买得到）要到 Phase 4 才计入；
- 等待时间改善对复购的影响、安全问题避免的伤害成本，都没有换算成金额；
- 熟食现做、包裹中转、退货模块尚未进入仿真（Phase 6）。
