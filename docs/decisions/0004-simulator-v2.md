# 决策记录 0004 · 模拟器第二轮升级

> 日期：2026-10-20 · 状态：已采纳

## 1. 分屏：场景与数据并排，切换标签不打断播放

- **决定**：工作区由「场景 | 分隔条 | 数据面板」组成，可左右互换、拖动调整比例（32%–78%）；对象详情改为场景上的浮动卡片，数据面板只放实时数据、策略对比、事件和门店定制。
- **理由**：用户要在不中断模拟的情况下同时看画面和数据；播放时钟本来就在 React 之外（决策 0003 第 3 条），切换标签只影响面板。

## 2. 策略对比放在第二个 Worker

- **决定**：每次重新仿真后 0.4 秒，在独立的 Worker 中用同样的输入跑三种策略。
- **理由**：对比要跑三遍；放在主 Worker 会让用户操作（改派、编辑）的反馈变慢。界面注明这是单次仿真，统计显著性见 Phase 1 的 30 次重复实验。

## 3. 布局编辑实时生效

- **决定**：每次修改先在草稿中校验，通过后防抖 350 毫秒自动应用并重新仿真；编辑期间不暂停；撤销 / 重做保留 50 步。「完成编辑」时还在防抖中的修改立即应用。
- **配套**：时间轴始终与生成它的门店模型配对（`simModel` / `simGeo`）。编辑器预览草稿布局，员工和车辆仍按仿真时的布局移动，新结果到达后再切换。否则草稿改变节点编号时，员工会走到不存在的节点。

## 4. 道路拥堵进入仿真引擎，默认关闭

- **决定**：`SimScenario.traffic` 可选；顾客按原计划出发（「我在路上」时刻不变），堵车推迟实际到店；ETA 信号按实际到店时间触发。
- **理由**：这是两种备货触发方式在高峰期表现不同的真实原因，值得量化。随机数按订单键控，不同策略面对同样的路况（公共随机数）。
- **约束**：强度为 0 时结果逐位相同；命令行默认不设置，Phase 1 的报告可复现。模拟器默认「一般」。

## 5. 周边环境和背景车流只用于画面

- **决定**：道路、建筑、背景车流、购物顾客的私家车和人由随机种子生成，不进入订单仿真；订单、取货车辆、汽车服务中心的车辆全部来自仿真结果。
- **背景车流模型**：每条车道上的车按智能驾驶员模型（IDM）跟车，红灯在停止线前停车，黄灯来不及停的通过；到达率随拥堵程度上升，超过路口通行能力时排队变长。这样画面上的堵车与仿真中的拥堵强度一致，但不需要一个完整的交通仿真。
- **画面时间**：背景车流最多按 8 倍速推进；取货车辆的进出动画按同样比例拉长。到店时刻、交付时刻始终是仿真时间。

## 6. 门店生成器：模板就是预设参数

- **决定**：`generateStoreConfig(params)` 生成完整配置；三个模板改为三组预设参数。重构前后三个模板逐项比较完全相同（除新增的空 `facilities`），并加了测试。
- **随机参数**：`randomGeneratorParams(seed)` 让规模、层数、百货通道、暂存规模和附属设施相互协调（例如两层门店一楼百货通道更少）。

## 7. 附属设施：可选字段，独立仿真

- **决定**：配置新增 `facilities`（目前只有 `AUTO_SERVICE`），zod 默认空数组，旧版 JSON 照常导入。汽车服务中心的车辆与店内拣货网络无关，用独立的离散事件仿真（`simulateAutoService`），共享事件内核与拥堵模型。
- **校验**：每侧最多一个设施、至少一个工位、营业时间有效。
- **几何**：设施建在门店一侧，正面与门店对齐；停车场覆盖门店和设施的正面，设施前方的车位作为等候车位，不给购物顾客使用。

## 8. 游戏级画面的实现方式

- **昼夜**：一个环境对象每帧由仿真时钟更新（太阳方向与颜色、环境光、天空色、夜色程度），路灯、车灯、窗户、店内照明都读它。
- **夜间照明不用实时光源**：店内物体用随夜色增强的自发光近似「店里亮着灯」，路灯和车灯用加法混合的光斑。几百盏实时光源会让帧率崩溃。
- **阴影**：只有太阳投射阴影，阴影相机覆盖门店和停车场；画质设置可以关闭，触屏设备默认关闭。
- **人物四肢**：躯干、头、双臂、双腿分别实例化，四肢几何体原点在关节处，按真实时间摆动。如果按仿真时间摆动，高倍速播放时会抽搐。

## 9. 文件名不能只差大小写

- **发现**：macOS 默认文件系统不区分大小写，`site.ts` 与 `Site.tsx`、`traffic.ts` 与 `Traffic.tsx` 等会被 TypeScript 和打包器当成同一个模块。
- **决定**：组件文件和同目录的逻辑模块使用不同的名字（例如 `Surroundings.tsx` / `site.ts`、`Fleet.tsx` / `traffic.ts`、`InStoreShoppers.tsx` / `shoppers.ts`）。
