# 决策记录 0006 · 模拟器第四轮升级

> 日期：2026-10-20 · 状态：已采纳

## 1. 到货与仓储取代原来的「夜班补货」模块

- **决定**：新的 `inbound.ts` 把到货车辆、叉车与手动搬运车、托盘货架、收货区和夜班补货放进同一个离散事件仿真；后仓布局（货架排、段、层，收货区，卸货门）由门店配置推导（`backroom.ts`），仿真引擎和画面共用。原 `nightCrew.ts` 删除。
- **理由**：用户要求卡车把整批货物用叉车放进库存仓库，并且仓库的存放、补充要能看到、大小可以定制。夜班补货需要的货源就来自这些托盘，分开建模会出现两套互相矛盾的库存。
- **规则**：卸货时叉车优先；放进货架和从高层取下都有举升时间（越高越慢）；同一货位同一时间只放一个托盘；夜间半挂车按各通道的补货需要配货；开门时货架约五成满。托盘记录进入时的箱数和逐次取货，画面按时刻显示剩余高度。
- **约束**：`simulateDay` 不变，命令行不运行这个模块，Phase 1 的结果不受影响。配置新增的 `backroom` 字段有默认值，模板只多出这个字段。

## 2. 叉车举升作为单独的轨迹片段

- **决定**：叉车开到货位后有一个单独的「举升」片段，记录目标高度、托盘和方向（放上 / 取下）。画面按片段内的进度升降货叉：放货时托盘在升到顶后留在货位上；取货时空叉升上去、托住托盘一边降一边倒车，把托盘放在货位前的地面。
- **理由**：最初用片段之间的空档推断举升，同一段货架不同层的货位在平面上重合，推断不出层高，货叉一直不动；托盘也会跟着货叉降回来再跳上去。
- **发现**：测试还发现同一个高层托盘可能被重复排进「取下」队列，已用待办集合去重。

## 3. 布局编辑的几何操作放进 store-config

- **决定**：画通道、两端吸附、旋转 90°、成组移动、复制粘贴、等距排列、暂存点吸附都写成 `editing.ts` 里的纯函数，直接修改草稿配置；模拟器只负责指针和快捷键。
- **吸附规则**：通道两端离垂直的走廊或通道不超过 3 米就接上去；两端都没接上时沿通道方向各向外找一条线段（最远 12 米，点一下时 80 米）；还接不上就不创建并说明原因。只支持横平竖直的通道。
- **新增校验**：横竖货架在货架段内交叉、通道超出楼层、线上订单暂存区压在货架上。400 个随机门店和全部预设仍然通过。
- **失败不留痕**：旋转、等距排列先在副本上试，全部失败时不产生修改，也不进入撤销历史。

## 4. 方案对比与报告

- **决定**：方案 = 一组完整设置 + 当天结果摘要 + 场景缩略图，保存在本机浏览器（空间不够时去掉缩略图再存）。A / B 对比复用策略对比的指标表；多天模拟在对比 Worker 里逐天运行，订单量按星期几浮动；报告导出为单个 HTML 文件（内联样式、图片和图表）或 Markdown。
- **经营账**：分为线上订单业务、汽车服务、后仓收货与补货三部分。模拟器不计算店内销售，而后仓补货服务的是整个门店，所以合计通常为负；界面和报告都写明「比较方案时看差值」，主指标用线上订单业务的净额。所有单价都是可调假设。
- **截图**：渲染一帧后立即读取画布，不需要开启 `preserveDrawingBuffer`。

## 5. 交通与人流

- **左转**：主路左转走保护箭头相位（排在主路直行之前），对向 45 米内没有行驶中的车时也可以在主路绿灯下转弯。只有保护相位时，单车道道路上等左转的车会把后面的直行车全部挡住，轻度拥堵下也排长队，与常见的「保护 + 许可式」左转不符。
- **变道**：必须变道（转弯车并到转弯车道）和自愿变道（前车慢则借道，前方空了回外侧）分开处理；目标车道前后都要有足够的空当；路口附近不变道；变道时车辆横向平移并略微偏转。
- **行人**：人行道和人行横道组成一个小网络，行人按最短路走；绿灯剩余时间不够走完就等下一轮。有人的横道把穿过它的车道登记为障碍物；转弯车辆在弧线末端前检查障碍物和目标车道的并入空间。
- **停车场柔性避让**：只沿车辆自身的左右方向横移（最多 1.6 米），正对面来车时各自向右让；不改变按时间推算的行驶进度，因此拖动时间轴时结果一致。
- **购物车回收**：回收栏占用双排车位中的一列；顾客放车与回收员巡回都按顾客停车记录推算，是时间的纯函数。

## 6. 一天之内变化的天气

- **决定**：「多变」天气按季节和周边环境的种子逐小时生成（马尔可夫转移，夏天午后多阵雨，冬天可能下雪，秋冬清晨多雾），相邻时段 30 分钟渐变。环境光照、雾、雨雪粒子数量、路面湿度和积雪都按连续的强度计算。
- **仿真**：同一份计划在 Worker 里转换成雨雪时段的减速窗口、逐小时的路况系数和全天订单量系数。

## 7. 画面细节

- 冷藏、冷冻柜朝通道的一面加灯光面板；天花板灯在地面上的光斑、招牌光晕、门口的暖光都用加法混合的贴图，不增加实时光源。
- 通道两端加促销端架（放在转弯留空里，不挡行走中线）；含熟食类别的靠墙通道后段用熟食服务柜台代替货架（只是画面，货位仍在）。
- 人物的发型、发色、肤色和身高由 seed 决定；孩子跟在部分顾客和行人身边。

## 8. 测试中发现并修复的问题

- 夜里托盘颜色发白：托盘材质的夜间自发光减弱。
- 停着的车辆朝向「继承」上一辆车：轨迹插值共用一个输出对象，停止时没有重算朝向；改为沿用本轨迹最近一次移动的方向。
- 托盘箱数显示为 0：引擎原地扣减箱数，记录下来的是结束时的值；改为记录初始箱数和取货记录。
- 外观随机数偶尔越界：按 255 归一化时可能等于 1，数组下标越界，改为除以 256。
