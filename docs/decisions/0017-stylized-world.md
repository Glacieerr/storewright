# 决策记录 0017 · Phase 10：游戏级的卡通画面与门店周边重新建模

> 状态：完成（2026-10-24）
> 作者要求（原话要点）：改善整套工作流的建模，效果达到游戏级别（例如风格化的开放世界游戏）；范围限于门店和周围的道路，四周的建筑可以放宽精细程度，但道路、桥梁、湖泊、码头要有较好的精细度；保留三维可视化、可操作、实时数据交互；完成后运行整套程序供人工验证。

---

## 1. 选型：留在 Three.js，全部程序生成

| 方案 | 结论 |
|---|---|
| 虚幻引擎 5（像素流送） | 不采用。画面要在服务器上渲染再串流到浏览器，演示站就不再是纯静态文件，也不能离线运行；场景里的实时数据（员工位置、车辆、告警、回放）要再做一套通信；本机也没有安装。 |
| 下载现成的模型和贴图包 | 不采用。素材授权要逐个核对，体积大，风格也难统一。 |
| **Three.js + React Three Fiber，程序生成几何体和画布贴图** | **采用。** 场景和数据在同一个页面里，原有的点选、编辑、孪生叠加层、回放、截图都不受影响；不下载任何素材，同一个随机种子总是同一片风景。 |

风格目标：明快的卡通渲染——两段式明暗、偏冷的暗面、天光勾出的亮边、深色描边、饱和而不刺眼的颜色、通透的天空和远山。

## 2. 画面流水线

1. **全局卡通着色**（`scene/style/toonStyle.ts`）：给所有卡通材质的原型挂一个着色补丁，统一加上柔和的两段明暗（渐变贴图换成带过渡带的两段式）和朝天一侧的轮廓光。参数是共享的 uniform（`scene/style/uniforms.ts`），由昼夜循环每帧更新一次，几百个材质不用逐个改代码。
2. **光照**：暖色阳光、偏蓝紫的环境光和半球光，暗面自然偏冷；色调映射改为保色的 Neutral，界面配色和场景配色更一致。
3. **后期处理**（`scene/style/PostFX.tsx`，中、高画质）：
   - 场景先画到带深度贴图的离屏缓冲；
   - 描边：原始深度在平面上随屏幕坐标线性变化（透视投影下也是），对它做二阶差分，只有外沿和棱角处不为零；外沿画在近的一侧，线宽一个像素；正交和透视两种相机都按像素对应的世界尺寸归一化，缩小看全景时细小的棱角线自动变淡；
   - 调色：轻微提高饱和度、暗部偏冷亮部偏暖、暗角；
   - 泛光（高画质）：只有亮度超过 1 的灯（路灯、灯笼、窗户、信号灯、店招）才会发光，白天不会糊成一片；
   - 色调映射与 sRGB 输出，最后抗锯齿（标准屏 SMAA，高分屏 FXAA）。
   - 截图（报告缩略图、导出 PNG）走同一条流水线。
4. **天空与远景**（`scene/style/Sky.tsx`）：天空画在所有不透明物体之后，只填没被挡住的像素；渐变、太阳与光晕、两层噪声的云（朝阳一侧亮）、夜里的月亮和闪烁的星星；场地外是带田野和树林色斑的远处地面，两圈低多边形远山，越远越淡。
5. **低画质**：不做后期处理和云，其余照常，适合性能较弱的设备。没有显卡加速（浏览器在 CPU 上软件渲染 WebGL）时默认用低画质（2026-10-29 补充，原因见 [13 号文档](../13-demo-and-deployment.md)第 6 节）。

## 3. 水系：湖、跌水、渠道、石拱桥、栈桥码头

水系由 `scene/terrain/waterPlan.ts` 的纯函数按种子生成（有单元测试）：

- **湖**在主路对面、门店右前方，岸线是加了三个频率起伏的椭圆；岸坡宽度随方位变化（有的地方是缓坡沙岸）；
- **跌水**：湖面（−1.0 米）高于渠道水面（−2.4 米），湖的东北角接一段石墙夹着的渠口，三级台阶的堰让湖水漫下去，堰下翻起白沫；
- **渠道与河**：从堰向北，穿过主路，沿后勤通道外侧流到场地后方；路口一带是石砌直墙（带压顶石），之后渐渐变成自然河岸并蜿蜒；
- **石拱桥**：桥面与路面齐平（车流和行人的计算完全不变），两侧桥面墙各开两个半椭圆拱洞，拱下是弧形拱腹，中间桥墩两头有分水尖；花瓶形栏杆柱（车削体）、方形望柱、四角灯笼；
- **栈桥码头**：北岸，横铺的木板、两根纵梁、木桩、略微下垂的绳栏、T 形平台；四条小船系在旁边，随水波起伏、轻微横摇；岸上是石板小广场（长椅、花坛、条纹遮阳篷的租船小亭）；
- **环湖步道**、堰下游的**拱形木桥**、湖边的路灯和长椅、岸边的树；
- **避让**：右侧的支路自动挪到水面之外；湖、河、广场都登记为禁建区，周边建筑、公园和树木都让开；
- **地形**：湖和河附近用 0.625 米的规则网格，高度由到水边线的有符号距离算出（岸上坡顶圆滑、越靠近水边越陡，水边线附近地形和水面交得干脆，不会大片闪烁）；网格线对齐渠道石墙；其余平地用大块矩形；
- **卡通水面**（`scene/terrain/waterMaterial.ts`）：不需要反射贴图——离岸越远越深、两层错开流动的水纹（河里顺流）、菲涅尔映出天色、太阳高光、岸边泡沫和一道道向岸推进的浪线、下雨时的涟漪；公园小水池用同一种水面。

## 4. 道路、门店与周边

- **路面**：沥青、人行道方砖、广场石板、木板、石墙、外墙金属板、屋面卷材都是画布生成的可平铺贴图，按世界坐标或三向投影取样，长方体怎么缩放都不会拉伸；花岗岩路缘石；车道线、路边线、停止线、导向箭头（按车道位置区分直行、左转、右转）；井盖和雨水篦子；标线改用受光照的材质，夜里不会自己发亮；
- **实时数据进到街景里**：线上取货车位的立牌有编号牌和状态灯，颜色跟着车位的实时情况变（空闲绿、有车在等蓝、等太久红色闪烁、正在交付琥珀色），仿真时来自仿真结果，数字孪生时来自门店的交付看板；卸货门的信号灯、夜里的窗户和路灯也都跟着数据和时钟；
- **街道设施**：带横臂的信号灯（灯箱有背板和遮光檐，左转灯挂在同一根横臂上）、弯臂路灯和停车场双臂灯（夜里在路面投下暖色光斑）、公交候车亭、消防栓、垃圾桶、限速牌；
- **门店外观**：石材勒脚、金属板外墙、竖向壁柱、高窗带、品牌色檐口带、入口两侧的通高玻璃幕墙、高出屋面的门头墙和店招（夜里发光）、女儿墙压顶、屋顶空调机组（风扇格栅、侧面百叶）、采光天窗、落水管；卸货口加了贯通的雨棚、门封、地面导向线和作业灯；入口外的护柱、花箱、长椅和垃圾桶；路边立牌换成石材底座的双柱灯箱；同一种材质的构件合并成一个几何体，剖切照常；
- **店内**：货架仍是一个个实例化的长方体（点选、叠加层颜色不变），朝通道的面在着色器里画出层板、价签条和成排的商品（宽窄、高低、颜色按哈希变化，同一款连着摆几个）；顶面和端面是叠加层颜色；看热度、存量时商品被数据颜色染色；塑胶地砖；
- **周边建筑**（细节适度）：程序化立面按楼层和开间画出窗户和窗框，商铺一楼是通长橱窗；夜里一半左右的窗户亮灯；住宅是出檐的彩色坡屋顶和烟囱，平顶楼有女儿墙压顶和屋顶设备；
- **树木**：阔叶树的树冠由几团起伏的球体堆成，法线朝树冠中心外推，卡通光照下是一整块柔和的明暗；针叶树是四层下垂的圆锥；灌木；树冠随风摆动，季节换颜色；
- **草丛与野花**（高画质）：草坪、绿岛、湖边和河岸的平地上撒一簇簇草叶，随风摆动，春夏有小花，积雪时隐藏；
- **车辆**：车身由侧面轮廓拉伸并倒圆角，前挡风玻璃倾斜、玻璃车厢、彩色车顶、B 柱、后视镜、格栅；仍是「车漆 + 细节」两个合并几何体，车流和停车的逻辑不变；
- **人物**：圆润的四肢、手、鞋和眼睛，网格车筐的购物车；
- **配色**：草地、树木、屋顶、沥青按季节重新配色，更饱和明快。

## 5. 不变的部分

- 仿真、车流、行人、停车、到货、孪生数据都不变；新的画面只读这些数据。
- 点选、右键菜单、跟随、编辑（包括门店生成器、换门店模板）、剖切、楼层、叠加层、孪生标签与告警、回放与推演、截图和报告都照常。
- 道路布局只有一处变化：右侧的支路会挪到水面之外。

## 6. 性能

- 实例化绘制、静态构件合并、草丛有数量上限并且只在高画质绘制；
- 有界面的 Chrome，1440 × 900、2 倍像素：高 / 中 / 低画质、等距和 3D 视角共 6 种组合都是 60 fps（显示器刷新率上限），每帧主线程约 4 ms；
- 三维场景的代码（gzip）约 84 KB，连同 Three.js 和 React Three Fiber 约 355 KB，按需加载。

## 7. 测试

- 新增 `scene/terrain/water.test.ts`（6 项）：同一种子同一片水系；湖在主路对面、不压道路停车场门店，建筑离水边至少 2 米，支路不压河道（三种门店规模 × 三种道路风格 × 三种地块 × 三个种子）；桥下是河床、桥面与路面齐平、两端落在平地上；湖面高于渠道水面、堰在两者之间、渠道段是直的；栈桥岸上一端在平地、尽头在湖里、小船都在湖面上；地形网格拼满场地、高度不高于地面。这项测试找出过一个问题：湖的北岸可能比跌水堰更靠北，地形细网格没有盖住那一段（已修正）。
- 原有单元测试、端到端测试和全流程走查全部重新运行。
