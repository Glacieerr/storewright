# 伪代码 03 · 一天的门店作业仿真

> 实现：`packages/sim-engine/src/day.ts`、`kernel.ts`

## 仿真内核

```text
queue ← 按 (时间, 加入序号) 排序的最小堆
function RUN(until):
    while queue 非空 且 队首时间 ≤ until:
        (t, action) ← POP(queue)
        now ← t
        action()                      // 同一时刻按加入顺序执行 → 结果完全确定
```

## 随机性：公共随机数

```text
// 所有随机事件都按「流名 + 键」取数，与调用顺序无关
找不到商品(line)      ← U(seed, "shelf", line.id) ≥ 商品的货架可得率
顾客到达(order)       ← slotStart + U(seed, "arrivalOffset", order.id) × 时段长度（含早到 / 迟到）
后仓真的有货(line)    ← U(seed, "backroom", line.id) < 商品的后仓可得率
```

不同策略面对完全相同的订单、缺货和到达时间，差异只来自策略本身。

## 主流程

```text
每小时整点：按排班设置各岗位人数（拣货、暂存、交付、后仓补取）
每 15 分钟：释放已锁单的订单
    分箱（策略：优化 / 凭目测）→ 分批（策略：按通道 / 按顺序）→ 路线（策略：旅行商 / S 形）
    批次进入拣货队列（按截止时间、加急优先）

拣货员空闲时：取队首批次
    for stop in 拣货清单（路线顺序）:
        走到 stop（距离 / 推车速度），找位
        for 每条拣货指令:
            if 找不到:
                if 允许替代 且 找到替代品: 拣替代品
                elif 库存记录显示后仓有货 且 来得及在截止前完成: 派发后仓补取（异步）
                else: 记为缺货
            else: 扫描放入
    回到暂存区；冷链批次记录用时并与时限比较

暂存员空闲时：取一辆到达的推车
    for tote in 推车: 选格位（同订单优先、就近）；策略决定是否扫描记录
    订单的所有框和大件都入位 → 订单就绪

顾客 / 司机：
    「我在路上」（基线）或 ETA ≤ 5 分钟（优化）→ 交付员可提前取框
    到达 → 进入先到先服务队列（EC-7）

交付员空闲时：
    优先服务已到达且订单就绪的会话（按到达先后）
    否则提前准备即将到达的会话
    服务 = 取框（未提前准备时）+ 推到车边 + 核验（行程一次 / 逐单）+ 逐框扫描装车 + 年龄核验
    完成 → 记录等待时间 = 完成 − 到达
```

## 输出指标（节选）

拣货效率、每件行走距离、推车行程数、超重 / 压坏风险 / 化学品混装框比例、冷链超时、满足率、缺货行与金额、未按时就绪比例、平均 / 80% 分位等待、等待 ≥ 8 分钟比例、门口停留、各岗位工时、单均人工成本。
