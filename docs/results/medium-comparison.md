# 仿真对比报告 · Mid-size supermarket（medium）

> 证据等级 **B**（仿真实验）：同一门店配置、同一订单流、同一组随机事件（公共随机数），
> 每个策略重复 **30** 天，报告均值 ± 95% 置信区间。所有门店、商品、订单均为合成数据。
> 这些数字只说明「在这些假设下」两种策略的差异，不代表任何真实零售商的数据。

## 1. 实验设置

| 项目 | 值 |
|---|---|
| 门店 | 1 层，19 条货架通道，2748 个货位，353 个暂存格位 |
| 营业时间 | 07:00–22:00，时段 60 分钟 |
| 日均订单 | 260 单，4842 行，7291 件 |
| 推车 / 框 | 每车 8 框；框内径 53×35×28 cm，上限 15.88 kg，装填系数 0.7 |
| 排班（人·小时 / 天） | 拣货 149，暂存 27，交付 65，后仓补取 12 |
| 种子 | 订单 1 起，每次重复递增 |

### 主要假设参数

| 参数 | 值 | 说明 |
|---|---|---|
| 推车速度 | 0.7 m/s | 校准后基线拣货效率约 70 件/工时，与公开基准（门店人工拣货 60–70 件/小时）一致 |
| 每个拣货点 / 每件 | 40 s / 10 s | 找位核对 / 扫描放入 |
| 暂存（记录 / 不记录） | 12 s / 8 s 每框 | 扫描格位多花几秒 |
| 交付取框（记录 / 寻找） | 6 s / 15 s + 60 s × 占用率 | 不记录格位时需要寻找，越满越难找 |
| 后仓补取 | 180–420 s | 库存记录不准率 0.25，后仓漏找率 0.1 |
| 顾客行为 | 「我在路上」点击率 0.7，位置共享率 0.6 | 早到 0.1，迟到 0.05 |
| 时薪 | $22 | 只用于换算成本 |

### 策略定义

| 环节 | 基线（无专门系统的中型店） | 优化（Storewright） |
|---|---|---|
| 分箱 | 凭目测按体积装框，不看重量、不分装化学品 | 体积 + 重量 + 压放顺序 + 化学品分装，单遍完成 |
| 分批 | 按订单顺序每 8 框一车 | 按通道重叠度全局划分 + 冷链时限约束 |
| 路线 | 按通道顺序 S 形 | 门店行走网络上的旅行商启发式 |
| 暂存 | 放好不记录，交付时寻找 | 扫描格位记录 |
| 准备 | 顾客点击「我在路上」时开始取框（行业常见做法） | 位置估算距离到达 ≤ 5 分钟时取框 |
| 行程核验 | 逐单核验 | 一个行程一次核验 + 记录车内位置 |
| 缺货 | 替代或缺货 | 替代 → 库存记录显示后仓有货时异步补取 → 缺货 |

> 基线刻意设得偏强（例如已经在「我在路上」时开始准备），宁可低估本系统的改进。

## 4. 如何解读

- 「判断」一栏只在 95% 置信区间不包含 0 时给出改善或变差；
- 结果依赖上面列出的假设参数，修改参数后重新运行即可得到新的结果；
- 复现：`npm run compare -- --template medium --reps 30 --seed 1 --ablation`。
